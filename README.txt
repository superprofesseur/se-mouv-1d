SE Mouv’ 1D - fichiers prets pour GitHub Pages

1. Creer un depot GitHub nomme se-mouv-1d.
2. Envoyer TOUT le contenu de ce dossier a la racine du depot.
3. GitHub : Settings > Pages > Build and deployment > Deploy from a branch.
4. Branch : main ; dossier : / (root) ; Save.
5. Attendre que GitHub affiche l'adresse https://VOTRE-COMPTE.github.io/se-mouv-1d/
6. Ouvrir cette adresse et verifier l'application.
7. Donner ensuite cette adresse a PWABuilder pour generer l'APK Android.

Pour 2027 : remplacer index.html par la version mise a jour au meme endroit. L'adresse GitHub Pages ne change pas.
